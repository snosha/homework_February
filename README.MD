## Описание

Это домашнее задание включает в себя создание классов `Product` и `Category`, а также их наследников `Smartphone` и `LawnGrass`, 
которые используются для моделирования товаров в магазине. 
В рамках задания реализованы:

- **Класс `Product`** с атрибутами: `name`, `description`, `price`, `quantity`.
- **Класс `Category`** с атрибутами: `name`, `description`, `products`.
- **Два класса-наследника `Product`**:
  - `Smartphone` (Смартфон) с атрибутами: `efficiency`, `model`, `memory`, `color`.
  - `LawnGrass` (Газонная трава) с атрибутами: `country`, `germination_period`, `color`.
- **Базовый абстрактный класс `BaseProduct`**, от которого наследуются все классы продуктов. 
- Он определяет общие методы и атрибуты для всех продуктов.
- **Ограничение сложения товаров:** можно складывать только объекты одного класса (реализовано с помощью `type()`).
- **Ограничение добавления в категорию:** можно добавлять только объекты `Product` и его наследников (используется `isinstance()`).
- **Класс-миксин, печатающий информацию о созданном объекте** при его инициализации. 
- Этот функционал реализован с помощью метода `__init__` в миксине, который выводит информацию о классе и параметрах при создании объекта.
- **Покрытие кода тестами более 75%** (`pytest --cov=src`).

## Структура проекта

- `src/` — основная папка с кодом:
  - `main.py` — основной файл, демонстрирующий работу классов.

## Описание классов

### **BaseProduct**

Базовый абстрактный класс для всех продуктов.
Он содержит общие атрибуты и абстрактные методы, которые должны быть реализованы в дочерних классах:

- `name`: Название продукта.
- `description`: Описание продукта.
- `price`: Цена продукта.
- `quantity`: Количество продукта на складе.

### **Product**

Класс `Product` наследуется от `BaseProduct` и реализует общую функциональность для всех продуктов:

- `get_product_info()`: Метод, возвращающий строку с информацией о продукте.
- Ограничение сложения объектов.
- Сеттер и геттер для цены, проверяющий, что цена положительна.

### **Category**

Класс `Category` представляет категорию продуктов с атрибутами:

- `name`: Название категории.
- `description`: Описание категории.
- `products`: Список объектов класса `Product`, принадлежащих категории.

### **Smartphone**

Класс-наследник `Product`, расширенный следующими атрибутами:

- `efficiency`: Производительность.
- `model`: Модель.
- `memory`: Объем встроенной памяти.
- `color`: Цвет устройства.

### **LawnGrass**

Класс-наследник `Product`, расширенный атрибутами:

- `country`: Страна-производитель.
- `germination_period`: Срок прорастания.
- `color`: Цвет.

### **Mixin**

Класс-миксин, который при создании объекта печатает в консоль информацию о том,
от какого класса и с какими параметрами был создан объект. 
Это позволяет отслеживать, когда и какой объект был создан, что полезно для отладки и логирования.
